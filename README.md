# Digital IC Design Assignments & ASIC Flow Projects

This repository contains Verilog/SystemVerilog implementations, testbenches, synthesis scripts, and Gate-Level Simulation (GLS) workflows developed during the Digital IC Design & ASIC Flow Course.

---

## 📁 Assignment Overview

| # | Assignment / Project | Description |
| :---: | :--- | :--- |
| **01** | `01_Verilog_DigCt` | Basic Digital Circuits in Verilog |
| **02** | `02_Up_Dn_Counter` | Up/Down Counter Design & Verification |
| **03** | `03_ALU_16B` | 16-Bit Arithmetic Logic Unit (ALU) |
| **04** | `04_RegFile_and_ALU` | Register File & ALU Integration |
| **05** | `05_1_FSM` | Finite State Machine (FSM) Design |
| **05** | `05_CRC` | Cyclic Redundancy Check (CRC) Generator |
| **06** | `06_UART_TX_Flow` | UART Transmitter (TX) Controller |
| **07** | `07_UART_RX` | UART Receiver (RX) Controller |
| **08** | `08_Clock_Divider` | Configurable Clock Divider |
| **09** | `09_DATA_SYNC` | Multi-bit Data Synchronizer |
| **10** | `10_ASYNC_FIFO` | Asynchronous FIFO Memory |
| **11** | `11_RST_SYNC` | Reset Synchronizer |
| **12** | `12_Multiplier_Synthesis` | Multiplier Logic Synthesis & Constraints |
| **13** | `13_GLS_Flow` | Gate-Level Simulation (GLS) & SDF Back-annotation |
| **System** | `System` | Integrated Top-Level System & Testbench |

---

## 🛠 Tools & Methodology
- **HDLs**: Verilog HDL, SystemVerilog
- **Simulation**: ModelSim / QuestaSim
- **Synthesis**: Synopsys Design Compiler (DC)
- **Flows**: RTL Simulation, Logic Synthesis, GLS with SDF Timing
