\section{Flow Architecture \& Objectives}

Gate-Level Simulation (GLS) is a critical verification milestone in the ASIC design flow. Unlike RTL simulation, GLS simulates the post-synthesis gate-level netlist with full SDF timing back-annotation, verifying that the gate-level implementation functions correctly under realistic delay conditions.

Furthermore, dynamic power consumption depends heavily on circuit switching activity. By dumping a Value Change Dump (\texttt{.vcd}) file during GLS and importing it into Synopsys PrimeTime PX, we obtain high-accuracy time-based dynamic power estimation.

\section{Stage 1: Logic Synthesis (Design Compiler)}

\subsection{RTL Configuration}
As specified in the assignment requirements, the parameter \texttt{Adder\_0\_Mult\_1} in \texttt{alu8\_top.v} was set to \texttt{0} to instantiate the 8-bit Adder module (\texttt{add\_unit}):

\begin{lstlisting}[style=logstyle, caption={RTL Configuration in alu8\_top.v}]
module alu8_top #( parameter Adder_0_Mult_1 = 0 ) (
    input  wire        clk, rst_n, en,    
    input  wire [7:0]  a, b,
    output wire [15:0] result,
    output wire        valid
);
    // Instantiates add_unit (8-bit Ripple-Carry Adder)
\end{lstlisting}

\subsection{Synthesis Output Files}
Synthesis was executed using Synopsys Design Compiler under a $100\text{ MHz}$ clock constraint ($10\text{ ns}$ clock period), generating the following key deliverables:
\begin{itemize}

  \item \textbf{\texttt{alu8\_top\_netlist.ddc}:} Binary Design Database ($31.2\text{ KB}$).
  \item \textbf{\texttt{alu8\_top.sdc}:} Synopsys Design Constraints ($7.4\text{ KB}$).
  \item \textbf{\texttt{alu8\_top.sdf}:} Standard Delay Format Timing File ($43.2\text{ KB}$).

\section{Stage 2: Gate-Level Simulation (QuestaSim)}

\subsection{Testbench Setup}
In \texttt{tb.v}, multiplier testcases were disabled and Adder testcases were enabled with VCD dumping configured to \texttt{VCD/Adder.vcd}:

\begin{verbatim}
initial begin
    rst_n = 0; en = 0; a = 0; b = 0;
    repeat (50) @(posedge clk);
    rst_n = 1;

    $dumpfile("VCD/Adder.vcd");
    $dumpvars(0, tb);

    // 10 Adder Testcases Executed (drive a, b -> check_add)
end
\end{verbatim}

\subsection{Simulation Execution Command}
GLS was launched in Mentor QuestaSim using the command:
\begin{verbatim}
vsim -do run.do &
\end{verbatim}

Where \texttt{run.do} loads the standard cell simulation library (\texttt{tsmc13\_m.v}), gate-level netlist (\texttt{alu8\_top\_netlist.v}), testbench (\texttt{tb.v}), and annotates worst-case SDF timing delays (\texttt{-sdfmax /tb/dut=alu8\_top.sdf}).

\section{Stage 3: PrimeTime PX Power Analysis}

\subsection{PrimeTime Execution Command}
Time-based dynamic power analysis was executed in Synopsys PrimeTime PX using:
\begin{verbatim}
pt_shell -f PT.tcl | tee pw.log
\end{verbatim}

PrimeTime annotated switching activity from \texttt{sim/VCD/Adder.vcd} across \textbf{93.65\% of design nets} and \textbf{100.00\% of leaf cells}.
